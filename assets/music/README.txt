Put .mp3 files in this folder. The lift picks one at random each trip.
Empty folder = no cabin music.

Host / dedicated server (and single player) control on/off:
  hssidelift music on | off
or edit HSSideLiftSettings.json in the world save (and %AppData%/7DaysToDie/HSSideLift/ on the host).
Joining clients use the host value. Their local JSON is ignored.
